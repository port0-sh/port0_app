About port0.sh

port0 is an open source exchange built on Miden. A safe harbor for any token.

Anyone can dock a pool for any token pair. There is no gatekeeper. The registry records a pool's code commitment, not a judgment, so any token can trade. Traders swap against the pool. Liquidity providers deposit both assets and hold LP tokens that carry a share of the reserves and the swap fees.

The contracts, the SDK, and the indexer are public. Anyone can run their own.

Built by mic0. Contact hello@port0.sh.
