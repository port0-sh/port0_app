Send with recall

The app passes recallBlocks = 20. After about 20 blocks the note must appear under Wallet notes for the sender if Bread built a P2IDE.

Wallet notes

Faulty trade

The note is valid and targets a real pool. With an unreachable minimum the quote is taken against a scaled pool, so the pool cannot pay it; with an expired deadline the pool refunds at expiry. Either way the input comes back as a P2ID under Wallet notes.
